## Implementation tasks

1. Compute settlement sources.
2. Support external payments + internal credits/rewards.
3. Allow net=0 settlement without Payment.
4. Emit order.settled atomically with downstream trigger.

## Acceptance criteria

- [ ] PAID payment alone does not bypass Order validation.
- [ ] Zero-net Order SETTLED has no fake Payment.

## Failure / edge cases

- **partial external payment:** reject as unsupported in MVP; generate a new exact-net obligation only after internal credits/rewards are applied
- **reward revoked before settlement:** recalculate/deny
