> Versão: 0.13
> Data: 2026-09-20
> Review: Auto-reviewed v0.13 — checked against Communication Policy and accessibility goals.

## Voice rules

- Prefer direct Brazilian Portuguese.
- Use short sentences and concrete verbs.
- Explain consequences before asking for irreversible actions.
- Avoid unnecessary jargon in customer-facing surfaces.
- In admin surfaces, use domain terms consistently with the Glossary.
- Never manufacture urgency, scarcity, certainty or payment confirmation.
- Avoid excessive exclamation marks and emoji.
- Use numbers when they clarify a decision.

## Tone by context

| Context | Tone |
|---|---|
| Dashboard insight | concise, analytical |
| Success | clear, restrained |
| Risk/incident | calm, action-oriented |
| Billing/overdue | respectful, factual |
| Support | patient, diagnostic |
| Referral | positive but optional |
| Security/destructive action | explicit, serious |
| AI uncertainty | transparent and non-defensive |

## Example

Prefer:

> Pagamento confirmado. A renovação foi registrada e o provisionamento está em andamento.

Avoid:

> 🎉 Sensacional!!! Seu pagamento deu super certo e já estamos liberando tudo!!!

## Admin language

Admin UI can use canonical English-like technical labels only where already standardized in domain/contracts, but visible navigation and descriptions should default to pt-BR.
