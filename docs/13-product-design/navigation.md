# Navigation Model

> Status: Canonical UX baseline
> Versão: 0.13
> Data: 2026-09-20
> Review: Auto-reviewed v0.13 — optimized for operator frequency and mobile fallback.

## Desktop

Persistent left rail:

- Home
- Inbox
- CRM
- Trials
- Subscriptions
- Support
- Revenue
- Operations
- Intelligence
- Growth
- Admin

Groups can expand to secondary routes.

Top bar:

- tenant switcher;
- global search;
- command palette;
- attention/HITL count;
- user menu.

## Navigation rules

- maximum two visible hierarchy levels in side navigation;
- deep entity screens use breadcrumbs;
- entity detail preserves context when opening side panels;
- destructive/financial actions are not placed in primary navigation;
- counters are reserved for actionable workload, not vanity totals.

## Mobile/tablet

Mobile is operational companion, not full dashboard replacement.

Bottom/compact navigation prioritizes:

1. Home
2. Inbox
3. Search
4. Attention
5. More

Financial configuration, complex analytics and bulk operations may require desktop while still remaining readable on tablet.
