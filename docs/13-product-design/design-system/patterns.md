# Design Patterns

> Status: Canonical baseline
> Versão: 0.13
> Data: 2026-09-20
> Review: Auto-reviewed v0.13.

## Attention-first page

Header → attention queue → primary KPIs → operational trends → secondary detail.

## Entity workspace

Entity summary header → important status → allowed actions → tabbed domain detail → activity/evidence side rail.

## External action

Intent → eligibility/policy check → confirmation when needed → execution → verification → evidence → final state.

## Unknown effect

Never use generic error toast only. Render persistent warning with verification status and block blind retry.

## Human review

Context → what AI tried → evidence → recommended options → human decision → resume path.

## Financial explanation

Revenue → discounts/rewards → provider cost → payment fee → allocated cost → contribution margin.

## Empty configuration

Explain prerequisite and offer one safe setup action; do not enable outbound behavior automatically.
