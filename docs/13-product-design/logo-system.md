## Working brand

**Synkroo Flow**.

## Recommended mark concept

A compact geometric mark formed by **two synchronized paths creating an abstract “S” and forward flow**. The visual idea should communicate:

- synchronization;
- continuous lifecycle;
- handoff between AI/human/systems;
- motion without using a generic lightning-bolt/robot icon.

## Required variants

1. Primary horizontal lockup: mark + `Synkroo Flow`.
2. Compact mark only.
3. Monochrome light.
4. Monochrome dark.
5. App icon/favicon.
6. Small-size simplified mark.

## Wordmark

Use a clean sans-serif. `Synkroo` may carry stronger weight, while `Flow` can use regular/medium weight or accent color.

## Exclusions

Do not use:

- robot heads;
- chat bubbles as the main mark;
- generic brain/circuit icons;
- TV/play-button symbolism, because the SaaS is broader than the initial vertical;
- overly complex gradients.

## Approval gate

Actual final vector artwork is blocked on:

- naming/trademark/domain clearance;
- visual review at 16/24/32 px;
- monochrome test;
- contrast/background test;
- user approval.

Until then, implementation should use a text wordmark and a temporary neutral app mark.
